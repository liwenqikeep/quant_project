# quant-frontend — 前端开发规范（预留）

## 状态说明

本项目前端处于规划阶段，技术栈、脚手架、目录结构均未确定。**本技能当前不包含任何代码风格要求**，只做两件事：登记联调契约基线、留出后续补充的口子。

## 当前唯一约束：联调契约

前端开发/联调时，唯一必须遵守的文档是根目录 docs/api-integration.md。其中基线包括：

- API 基础路径 /api/v1（健康检查 /health 除外），JSON UTF-8，时间 ISO8601，日期参数 YYYYMMDD。
- 统一响应结构 { code, message, data, request_id, timestamp }；code=0 成功，非 0 按错误码表分类处理。
- 分页参数 page/page_size，响应含 items/total/page/page_size。
- 金额单位元、比例用小数（0.0005 = 万分之五），股票代码 000001.SZ 格式。
- 前端不得自行假设接口行为；契约未定义的内容以联调文档为准，必要时在文档补充后再实现。
